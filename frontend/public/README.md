# Public data generation

`exhibit.json` must be generated on the developer's machine using
`python3 -m scripts.export_public --repo external/click --report reports/click-history.json --confirm-public-source`.

This export requires every displayed case to pass an independent Git-object audit.
Precomputed Gemma prose is literary output, and remains explicitly unverified.
Do not deploy until exhibit.json exists and includes real cases and local Gemma responses.
